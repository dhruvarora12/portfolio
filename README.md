# Dhruv Arora — Personal Portfolio

A highly optimized, minimalist, and dynamic personal portfolio built with modern web technologies. This application showcases a dark, premium aesthetic with subtle animations, video backgrounds, and responsive layouts to serve as a comprehensive profile for a Backend & AI Engineer.

## 🚀 Live Demo

"https://dhruvarora-portfolio.netlify.app/"

## 🛠️ Technology Stack

- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS (with custom design tokens and utility configurations)
- **Routing:** React Router v6
- **Animations:** Framer Motion & CSS keyframes
- **Icons:** Lucide React

## ✨ Key Features

- **Component-Driven Architecture:** Modular pages (`AboutSection`, `ExperienceSection`, `ProjectsSection`, `ContactSection`, etc.) for seamless scaling and updates.
- **Premium Design System:** A deep dark orange-tinted background (`#0f0800`), radial glow lighting, and SVG noise filters to provide depth and texture.
- **Dynamic Routing & Loading:** Employs an interactive loading screen overlay and smooth cross-page routing managed by `AnimatePresence`.
- **Responsive Geometry:** Typography scaling (`clamp()`) and fluid tailwind grids (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`) guarantee perfect layouts across all screen topologies.
- **Video Hero Section:** A customized contrast-adjusted MP4 background in the hero serving as an ambient backdrop.
- **Type-Safe:** Strict TypeScript configuration ensuring 0 compile-time errors for production deployments.

## 📦 Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhruvarora12/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   *The app will run locally at `http://localhost:5173/`*

## 🏗️ Building for Production

Compile the project into a highly-optimized, minified bundle:

```bash
npm run build
```

This will run the TypeScript compiler (`tsc`) and Vite build pipeline, outputting the artifacts to the `/dist` directory. The project is pre-configured to be deployed immediately via CI/CD orchestrators like Netlify or Vercel.
